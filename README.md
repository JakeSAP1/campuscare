# CampusCare

Система записи на консультации и психологическую поддержку студентов: психологи, карьерные консультанты и тьюторы университета вместо живой очереди и телефона.

Учебный проект (вариант 6): vanilla JavaScript + Express + JSON-хранилище, без сборки и фреймворков.

## Что умеет

- **Роли.** Студент и специалист, регистрации и вход с сессиями (пароли — scrypt, доступ — Bearer-токены).
- **Запись.** Специалист выбирает тип консультаций (психолог / карьерный / тьютор), специализацию, формат приёма (онлайн/очно), часы работы. Слоты генерируются на 14 дней вперёд.
- **Анкета.** Перед первой консультацией у специалиста студент заполняет анкету (курс, запрос, опыт) — она видна специалисту в заявке.
- **Согласование времени.** Заявка создаётся в статусе «ожидает подтверждения»; специалист подтверждает, предлагает другое время (перенос) или отменяет — вторая сторона получает уведомление и подтверждает новое время.
- **Кабинет студента.** Предстоящие консультации, история, отмена, повторная запись, заметки себе.
- **Кабинет специалиста.** Заявки, подтверждённые, архив, приватные заметки по консультациям (видны только специалисту), список клиентов с числом визитов.
- **Отзывы.** После проведённой консультации студент оставляет анонимную оценку 1–5; рейтинг и список отзывов видны в каталоге и на карточке.
- **Уведомления.** Колокольчик в шапке: новые заявки, подтверждения, отмены, переносы, отзывы и напоминания о консультации за 24 часа (приходят при входе в систему).

## Запуск

```
npm install
npm start        # http://localhost:3000
```

При первом запуске создаётся `data/db.json` с демо-данными: 6 специалистов, студенты, слоты на 14 дней, история консультаций с отзывами. Чтобы начать с чистого листа — удалите файл `data/db.json`.

## Структура

```
server/
  index.js      — Express: JSON API + статика фронтенда
  api.js        — все эндпоинты: авторизация, каталог, записи, отзывы, уведомления
  db.js         — JSON-хранилище с атомарной записью (tmp + rename)
  seed.js       — демо-данные при первом запуске
  passwords.js  — scrypt-хеширование
public/
  index.html    — оболочка SPA
  css/styles.css
  js/
    app.js      — hash-роутер, шапка, колокольчик, поллинг уведомлений
    api.js      — fetch-клиент с Bearer-токеном
    ui.js       — экранирование, тосты, модалки, форматирование, звёзды
    state.js    — состояние клиента
    views/      — страницы: auth, catalog, specialist, booking, student,
                  specialist-cab, review
```

## API (кратко)

- `POST /api/register`, `POST /api/login`, `POST /api/logout`, `GET /api/me`
- `GET /api/specialists?type=&format=`, `GET /api/specialists/:id`, `/:id/slots`, `/:id/reviews`
- `POST /api/bookings`, `GET /api/my/bookings`, `GET /api/my/schedule`, `GET /api/my/clients`
- `POST /api/bookings/:id/confirm | cancel | reschedule | complete | spec-note`
- `POST /api/reviews`
- `GET /api/notifications`, `POST /api/notifications/read`

Доступ проверяется по роли: расписание и заметки — только специалисту, записи и отзывы — только студенту.
